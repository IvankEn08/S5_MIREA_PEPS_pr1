# ПЭПС. Практическая работа № 1 — микроконтроллерная схема ввода-вывода

Учебный проект по дисциплине «Программирование электронных приборов и систем», РТУ МИРЭА.
Схема ввода-вывода на микроконтроллере **STM32F103C8**: состояние входного ключа передаётся
на светодиодный выход. Схема собрана и промоделирована в **Proteus 8.17**, прошивка написана
на языке Си и собрана в **CooCox CoIDE 1.7.8** с компилятором **GNU ARM Embedded 5.4**.

Индивидуальный вариант 4: вход **PA6** (ключ), выход **PA7** (светодиод через резистор 330 Ом).

## Как работает программа

Периферия настраивается прямой записью в регистры:

| Действие | Регистр |
|---|---|
| тактирование порта GPIOA | `RCC->APB2ENR`, бит `IOPAEN` |
| режим линий PA6 и PA7 | `GPIOA->CRL`, поля MODE/CNF (линии 0–7; для линий 8–15 используется `CRH`) |
| чтение состояния входа | `GPIOA->IDR` |
| управление выходом | `GPIOA->BSRR` — атомарная установка и сброс отдельных бит |

Логика: `PA6 = 1` → светодиод горит, `PA6 = 0` → погашен. Уровень включения светодиода
активный высокий: анод через резистор к выводу микроконтроллера, катод на общий провод.

Номера выводов вынесены в макросы в начале `main.c`, поэтому переход на другой индивидуальный
вариант сводится к правке одного блока.

## Сборка

**В CoIDE:** открыть проект STM32F103C8, добавить `main.c`, указать путь к компилятору
(`Project → Select Toolchain Path`, например `C:\Program Files (x86)\GNU Tools ARM Embedded\5.4 2016q3\bin`),
собрать по F7. Готовый HEX в репозитории сохранён как `PR1_STM32_firmware.hex`.

**Без IDE**, только компилятором:

```
arm-none-eabi-gcc -mcpu=cortex-m3 -mthumb -O1 -Wall -DSTM32F10X_MD ^
  -Icmsis -Icmsis_boot -ffunction-sections -fdata-sections ^
  -T stm32f103c8.ld -nostartfiles -Wl,--gc-sections ^
  main.c cmsis_boot/system_stm32f10x.c cmsis_boot/startup/startup_stm32f10x_md.c -o PR1.elf
arm-none-eabi-objcopy -O ihex PR1.elf PR1.hex
```

## Моделирование в Proteus

Открыть `PR1_proteus_project.pdsprj`, в свойствах микроконтроллера (двойной клик) указать в поле
**Program File** файл `PR1_STM32_firmware.hex`, задать **OSC Frequency** = 8 MHz.
Напряжение питания объявляется в `Design → Configure Power Rails`: шина `3.3V` с напряжением 3,3 В.
Запуск — кнопка Play; переключение ключа мышью меняет состояние светодиода.

## Состав схемы

| Обозначение | Элемент | Назначение |
|---|---|---|
| U1 | STM32F103C8 | микроконтроллер |
| SW1 | SW-SPDT | входной ключ: перекидывает PA6 между 3,3 В и общим проводом |
| R1 | резистор 330 Ом | ограничение тока светодиода |
| D1 | LED-RED | светодиодный выход на PA7 |
